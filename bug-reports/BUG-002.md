# BUG-002 — System Confirms Reservation with Invalid Payment Information

## 1. Bug Summary

**ID:** BUG-002
**Title:** System confirms reservation with invalid payment information
**Requirement:** REQ-06 / REQ-07
**Test Case:** TC04
**Priority:** High
**Severity:** Critical
**Environment:** Test
**Platform:** Web
**Status:** Closed

---

## 2. Description

The system confirms a reservation even when invalid payment information is provided.

This behavior violates the payment validation requirements and allows a reservation to be confirmed without a successful payment.

---

## 3. Preconditions

* The EventHub website is accessible.
* The user is logged in.
* The user has selected an available event.
* The user has selected the tickets and proceeded to the payment page.

---

## 4. Test Data

| Field               | Value         |
| ------------------- | ------------- |
| Event               | Rock Festival |
| Payment Information | Invalid       |

---

## 5. Steps to Reproduce

1. Access the EventHub payment page.
2. Enter invalid payment information.
3. Attempt to confirm the reservation.

---

## 6. Expected Result

The system should reject the payment and should not confirm the reservation or display a reservation confirmation.

---

## 7. Actual Result

The system accepts the invalid payment information, confirms the reservation, and displays a reservation confirmation.

---

## 8. Impact

Users may be able to obtain confirmed reservations without completing a valid payment.

This represents a critical business and payment validation issue because the reservation confirmation process is not correctly dependent on successful payment validation.
