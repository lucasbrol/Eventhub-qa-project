# BUG-001 — System Allows Users to Reserve More Than 6 Tickets

## 1. Bug Summary

**ID:** BUG-001
**Title:** System allows users to reserve more than 6 tickets
**Requirement:** REQ-03
**Test Case:** TC02
**Priority:** High
**Severity:** High
**Environment:** Test
**Platform:** Web
**Status:** Closed

---

## 2. Description

The system allows users to select more than the maximum allowed quantity of 6 tickets in a single reservation.

This behavior violates the defined ticket quantity requirement.

---

## 3. Preconditions

* The EventHub website is accessible.
* The user is logged in.
* An event with available tickets exists.

---

## 4. Test Data

| Field                           | Value         |
| ------------------------------- | ------------- |
| Event                           | Rock Festival |
| Available Tickets               | 10            |
| Maximum Tickets per Reservation | 6             |
| Attempted Quantity              | 7 tickets     |

---

## 5. Steps to Reproduce

1. Access the EventHub website.
2. Select the "Rock Festival" event.
3. Select 7 tickets for the reservation.
4. Attempt to proceed with the reservation.

---

## 6. Expected Result

The system should prevent the user from reserving more than 6 tickets in a single reservation.

---

## 7. Actual Result

The system allows the user to select 7 tickets in a single reservation.

---

## 8. Impact

Users can exceed the maximum ticket quantity defined by the system, which may violate the application's business rules and result in reservations containing an invalid number of tickets.

---

## 9. Retest

### Initial Test

**Result:** FAIL

The issue was successfully reproduced during the initial test execution.

### Retest

**Result:** PASS

The system now prevents users from reserving more than 6 tickets in a single reservation.
